# Dania Yasir Portfolio

A one-page static portfolio built with HTML, CSS, and simple JavaScript. It is ready for Netlify Drop, GitHub Pages, Cloudflare Pages, or Vercel static hosting.

## Files

- `index.html` — the structure and content of the portfolio: navigation, hero, projects, skills, about, and contact.
- `styles.css` — all visual styling, responsive layouts, colors, typography, cards, buttons, and mobile behavior.
- `script.js` — three small behaviors only: mobile menu, automatic footer year, and scroll-reveal animation.
- `assets/images/` — Dania's real profile photo and real project/report evidence images.
- `assets/docs/Dania_Yasir_CV.pdf` — downloadable CV.
- `assets/docs/FlyRank_Content_Decline_Report.pdf` — FlyRank final model report.
- `assets/docs/Freight_Rate_Prediction_Report.pdf` — Freight Rate Prediction technical report.
- `DNS_Walkthrough.md` — first-person DNS explanation for the PF-04 assignment. Review it and adjust the wording so it sounds fully natural to you before submission.

## Deploy on Netlify

1. Keep the folder structure exactly as provided.
2. Open Netlify Drop.
3. Drag the entire `dania-portfolio` folder onto the deployment area.
4. Wait for the live HTTPS URL.
5. In Netlify, go to Site configuration and change the site name to a clean name such as `dania-yasir` if it is available.
6. Test the public URL in a private/incognito browser window.
